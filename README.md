# Ejercicios de Programación en Java

Este repositorio contiene 10 ejercicios diferentes resueltos como práctica de fundamentos de programación.

## Descripción

El objetivo de este trabajo es aplicar conceptos básicos de programación usando Java, tales como variables, entrada de datos, operaciones matemáticas, condicionales, ciclos, acumuladores y validaciones.

## Ejercicios incluidos

1. **Costo de una compra con descuento**
2. **Calculadora básica**
3. **Conversión de kilómetros a metros y centímetros**
4. **Determinar si un año es bisiesto**
5. **Contador de números positivos, negativos y ceros**
6. **Suma de números pares hasta N**
7. **Potencia de un número**
8. **Invertir un número entero**
9. **Contar vocales en una palabra**
10. **Menú de operaciones matemáticas**
